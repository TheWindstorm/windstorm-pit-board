# Board

Run this Bash command:

- with no argument: `pitboard board --plain`
- when the argument is `all`: `pitboard board --all --plain`

(If `command -v pitboard` finds nothing, use `~/.pitboard/bin/pitboard`.)

Argument: $ARGUMENTS

Show the command's output exactly as printed, inside one code block, with no comment before or after it.
